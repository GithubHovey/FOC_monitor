# 电机通信协议可视化手册

## 📊 协议概览

### 数据包结构图
```
┌─────────────────────────────────────────────────────────────────────────┐
│                           14字节数据包格式                               │
├─────┬─────┬───────────────────────────────────────────────┬─────┬─────┤
│ 包头 │ 命令 │              数据区 (10字节)                    │ 校验 │ 包尾 │
│ 0xAA │ 0xXX │  Byte2  │ Byte3  │ Byte4  │ ...  │ Byte11  │ CHK │ 0x55 │

```

## 🎯 命令速查表

| 命令字 | 命令名称 | 功能描述 | 发送数据 | 应答数据 |
|--------|----------|----------|----------|----------|
| **0x02** | 读数据 | 读取电机参数 | 数据ID | 4字节数据 |
| **0x01** | 写数据 | 写入电机参数 | 数据ID+4字节数据 | 写入确认 |
| **0x03** | 启动电机 | 启动电机运行 | 无 | 状态+工作模式 |
| **0x04** | 停止电机 | 停止电机运行 | 无 | 状态+工作模式 |
| **0x05** | 模式设置 | 设置控制模式 | 模式ID | 状态+当前模式 |
| **0x06** | 接口模式 | 设置接口类型 | 接口ID | 状态+当前接口 |
| **0x07** | CAN ID | 设置CAN地址 | CAN ID | 状态+当前CAN ID |
| **0x08** | 零位设置 | 设置零位角度 | 2字节角度 | 状态+当前零位 |
| **0x09** | 状态上报 | 获取实时状态 | 无 | 电流+速度+位置+状态 |
| **0x0A** | 力矩控制 | 控制力矩输出 | 2字节电流 | 实时状态 |
| **0x0B** | 速度控制 | 控制电机转速 | 2字节速度 | 实时状态 |
| **0x0C** | 位置控制 | 控制电机位置 | 2字节位置 | 实时状态 |
| **0x0D** | 运控控制 | 综合运动控制 | 电流+速度+位置+Kp+Kd | 实时状态 |
| **0x0E** | 当前零位 | 设置当前为零位 | 无 | 状态+当前零位 |

### 1. 基础控制命令

```
📋 停止电机命令 (0x04)
┌─────────────────────────────────────────────────────────┐
```

#### 模式设置命令
```
📋 模式设置 (0x05)
┌─────────────────────────────────────────────────────────┐
│ 发送包：AA 05 [模式ID] 00 00 00 00 00 00 00 00 [CHK] 55 │
│ 应答包：AA 05 [状态] [当前模式] 00 00 00 00 00 00 00 [CHK] 55 │

🎮 模式选项：
```

### 🔍 数据ID分类速查
```
⚡ 电流相关：0x10-0x15
├─ 相电流目标值：0x10, 0x12, 0x14
└─ 相电流当前值：0x11, 0x13, 0x15

🚀 速度相关：0x16-0x17
├─ 转速目标值：0x16
└─ 转速当前值：0x17

⚡ 电压相关：0x18-0x1B
├─ Q轴电压：0x18(目标), 0x19(当前)
└─ D轴电压：0x1A(目标), 0x1B(当前)

🔧 配置参数：0x1C-0x36
├─ 系统限制：0x1C(最大电流), 0x1D(母线电压)
├─ 电机参数：0x1E(极对数), 0x31(机械零位)
├─ PID参数：0x26-0x2E (三环PID)
└─ 诊断信息：0x2F, 0x35, 0x36(执行时间)
```

## 🔄 典型操作流程

### 1. 电机启动流程
```
🚀 启动流程：
1️⃣ 模式设置 → 0x05 [模式ID]
2️⃣ 启动电机 → 0x03
3️⃣ 状态监控 → 0x09 (可选)
```

### 2. 运动控制流程
```
🎮 控制流程：
1️⃣ 选择控制模式 → 力矩/速度/位置
2️⃣ 发送控制命令 → 0x0A/0x0B/0x0C
3️⃣ 实时监控 → 0x09
```

### 3. 参数配置流程
```
⚙️ 配置流程：
1️⃣ 写参数 → 0x01 [参数ID] [数值]
2️⃣ 读验证 → 0x02 [参数ID]
3️⃣ 保存配置 → 系统自动保存
```

## 🛠️ 调试工具示例

### 串口调试助手格式
```
# 启动电机测试

期望：AA 03 00 01 00 00 00 00 00 00 00 00 00 04 55

```

### Python测试脚本模板
```python
import serial
import struct

def send_command(cmd, data=b'\x00'*10):
    packet = b'\xAA' + bytes([cmd]) + data
    checksum = sum(packet) & 0xFF
    packet += bytes([checksum, 0x55])
    return packet

# 启动电机
ser.write(send_command(0x03))
```
